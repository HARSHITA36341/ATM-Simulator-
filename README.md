# ATM Simulator

A command-line ATM simulator built in Python using Object-Oriented Programming (OOP).

![ATM Simulator](https://github.com/HARSHITA36341/ATM-Simulator-/blob/main/atm_output.png?raw=true.jpeg)

## Features
- Create a PIN with an initial balance
- Change PIN (after verifying the current PIN)
- Check balance (PIN required)
- Withdraw money (PIN required, with insufficient balance check)
- Exit

## Concepts Used
- Python classes and objects
- Methods and `self`
- `if / elif / else` conditions
- User input handling

## How to Run
1. Install Python 3
2. Download `atm.py`
3. Run in terminal:

```
python atm.py
```

## Sample Flow
1. Choose `1` to create a PIN and set an initial balance
2. Choose `4` to withdraw money after entering the PIN
3. Choose `3` to check the remaining balance
4. Choose `5` to exit
